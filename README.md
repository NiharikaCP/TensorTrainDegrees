# Degrees of Order-3 Tensor Train Varieties

Julia code to compute the degree of an order-3 tensor train variety
$\mathrm{TT}_{\mathbf{d},\mathbf{r}}$, with format $\mathbf{d} = (d_1,d_2,d_3)$ and TT-ranks
$\mathbf{r} = (r_1,r_2)$, using a purely combinatorial procedure: counting pairs of
non-intersecting lattice path families on the two flattenings of the tensor. No external
packages are required — everything is written in Base Julia.

## Background

For an order-3 tensor $\psi \in \mathbb{C}^{d_1\times d_2\times d_3}$, the tensor train
variety $\mathrm{TT}_{\mathbf{d},\mathbf{r}}$ is cut out by the ideal $J = I_1 + I_2$, where $I_1$ 
is generated by the $(r_1+1)$-minors of the flattening $\psi^{(1)} \in \mathbb{C}^{d_1 \times d_2d_3}$ 
and $I_2$ by the $(r_2+1)$-minors of
$\psi^{(2)} \in \mathbb{C}^{d_1d_2 \times d_3}$. Under a diagonal term order, the initial ideal $J_\succ = I^{(1)}_\succ + I^{(2)}_\succ$ is Cohen–Macaulay, and its minimal primes
correspond bijectively to pairs of non-intersecting lattice path families:

* $(P_1,\dots,P_{r_1})$ on $\psi^{(1)}$, where $P_\ell$ runs from the $\ell$-th entry of the
  last row to the $\ell$-th entry of the last column using only "up" and "right" steps, and
* $(Q_1,\dots,Q_{r_2})$ on $\psi^{(2)}$, defined analogously.

The degree of $\mathrm{TT}_{\mathbf{d},\mathbf{r}}$ equals the number of such pairs for which

$$\bigl|(\textstyle\bigcup_\ell P_\ell) \cap (\bigcup_\ell Q_\ell)\bigr| = \dim \mathrm{TT}_{\mathbf{d},\mathbf{r}},$$

where the dimension is given by the standard TT parameter count

$$\dim \mathrm{TT}_{\mathbf{d},\mathbf{r}} = d_1 r_1 + r_1 r_2 d_2 + r_2 d_3 - r_1^2 - r_2^2.$$

See the paper for the full statement and proof (Proposition "degree of an order 3 tensor
train variety").

## Requirements

Julia ≥ 1.6, no external packages. (`run_examples.jl` uses the `Printf` standard library,
included with every Julia installation.)

## Usage

```julia
include("degree_TT.jl")

compute_degree(3, 3, 3, 2, 2)
# 306

compute_degree(4, 4, 4, 2, 2; verbose=true)
# prints family counts and target dimension, then returns 261560

### API

- **`lattice_paths(r0, c0, r1, c1)`** — all up/right lattice paths from cell $(r_0,c_0)$ to
  cell $(r_1,c_1)$.
- **`noncrossing_path_families(p, q, t)`** — all $t$-tuples of pairwise non-intersecting
  lattice paths on a $p\times q$ grid, connecting $(p,\ell)$ to $(\ell,q)$ for
  $\ell=1,\dots,t$. 
- **`tt_dimension(d1, d2, d3, r1, r2)`** — dimension of $\mathrm{TT}_{\mathbf{d},\mathbf{r}}$.
- **`compute_degree(d1, d2, d3, r1, r2; verbose=false)`** — the degree, via the
  path-family-pair count described above.
- **`compute_degree_check_uniqueness(d1, d2, d3, r1, r2; verbose=false)`** — same
  computation, but additionally checks whether the map from valid path-family pairs to
  minimal primes is injective on the given input; returns
  `(degree, n_distinct_primes, injective)`.
